# CityQuest

Learn about the city and the people behind it, in a fun, interactive way.

City Quest is an interactive educational web app for kids that teaches them about their city and the government behind it. Tap the buildings on a cartoon city map to learn what each one does, who works there, and how it is paid for.

Built by Hridhaan Shah (7th grade) for the 2026 Congressional App Challenge (WA-01).

**Live demo:** https://my-city-quest.netlify.app/

## How to play

There are two levels:

- **Explorer (ages 5–10)** — Tap the buildings on the map to learn what they do. Collect passport stamps, listen to read-aloud descriptions, and try the activities: Find It quiz, Mayor Day, Budget game, Directory, and Family Tree.
- **Pathfinder (ages 11–14)** — The same city, but more advanced. More buildings, deeper cards with jobs, funding, and budget shares, plus XP ranks, Dilemmas, a Budget game, Law-making (order the 7 steps to making a law), and Government Levels.

But really, any age can play it.

## How to run it

1. Download or clone this repo.
2. Open `homepage.html` in any modern web browser (you need internet — the map uses the Leaflet library from a CDN).
3. Click **Explorer** or **Pathfinder** and start exploring.

No build step, no install, no server needed.

## Built with

- HTML, JavaScript, and CSS (written in VS Code)
- [Leaflet](https://leafletjs.com/) — open-source library for the map pins and zoom
- AI helped make the city map image and some of the code
- Hosted on Netlify

## The idea

Have you ever seen a kid walk by the city hall and tell you that it was the library? This app fixes that. Kids learn what each government building does, what services it offers, and who is responsible for their city.
